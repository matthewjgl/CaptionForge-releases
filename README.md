# CaptionForge downloads

Installer releases and update feed for CaptionForge on Apple silicon. Source code is private.

The first installer is being prepared. No friend-ready release is currently published.

Updates will replace the app, Final Cut extension and Timeline Helper together, preserving local projects, settings and downloaded models. Models download on first analysis. macOS administrator approval and optional Accessibility permission for Timeline Helper are required; the installer cannot grant those permissions.

Current app licensing: five Basic presets and three successful transcriptions per month without activation. Pro activation is not configured in the current build. Broad transcription accuracy and repeated timeline-drop acceptance remain in testing.
